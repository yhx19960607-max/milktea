# 奶茶真实数据采集模板

## 使用说明

1. 去品牌官方 App / 小程序 / 官网，找到产品的热量（卡路里）信息
2. 按下面的格式填写每一行数据
3. 填完后发给我，我来批量导入云端并触发审核

## 数据字段说明

| 字段 | 必填 | 说明 | 示例 |
|---|---|---|---|
| brand | ✅ | 品牌名 | 蜜雪冰城 |
| name | ✅ | 产品名 | 珍珠奶茶 |
| size | ✅ | 杯型（中杯/大杯/超大杯） | 中杯 |
| volume | ⬜ | 容量（毫升），不知道可留空 | 500 |
| sugar | ✅ | 糖度（无糖/三分糖/五分糖/七分糖/标准糖/全糖） | 标准糖 |
| ice | ✅ | 冰量（去冰/少冰/正常冰/多冰） | 正常冰 |
| toppings | ⬜ | 配料，用顿号「、」分隔 | 珍珠、椰果 |
| totalKcal | ✅ | 总热量（大卡） | 380 |
| sourceUrl | ✅ | 来源网址（官网/App 页面链接） | https://... |
| sourceProvider | ✅ | 来源提供方 | 蜜雪冰城官网 |
| sourceType | ⬜ | 来源类型，默认 official | official |
| capturedAt | ⬜ | 采集日期（YYYY-MM-DD），默认今天 | 2026-09-09 |

## 采集格式（CSV）

每行一条数据，用逗号分隔，按下面顺序填写：

```
brand,name,size,volume,sugar,ice,toppings,totalKcal,sourceUrl,sourceProvider,sourceType,capturedAt
```

### 示例

```csv
brand,name,size,volume,sugar,ice,toppings,totalKcal,sourceUrl,sourceProvider,sourceType,capturedAt
蜜雪冰城,珍珠奶茶,中杯,500,标准糖,正常冰,珍珠,380,https://www.mixue.com/nutrition,蜜雪冰城官网,official,2026-09-09
CoCo都可,鲜芋奶茶,中杯,500,标准糖,正常冰,芋泥,420,https://www.coco.com/nutrition,CoCo官网,official,2026-09-09
```

## 注意事项

- **只填官方数据**（品牌官网、官方 App、官方小程序里标注的热量），第三方估算不算
- 如果品牌只公布「每100ml热量」而没有整杯热量，也填上，备注在 sourceUrl 里说明
- 同一款产品不同糖度/冰量/配料算不同条数据，分开填
- 截图存档放在 `data/screenshots/` 文件夹，文件名用「品牌_产品名.png」
- 不知道的字段留空即可，不要瞎猜
