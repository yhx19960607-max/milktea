# 奶茶计算器开发说明

更新时间：2026-09-09 17:12

## 项目简介

这是一个微信小程序项目，目标是开发「奶茶计算器」，帮助用户记录饮食、运动、热量和奶茶选择，并逐步接入更多运动与健康数据来源。

## 在新电脑上继续开发

1. 安装 Git 和 Codex 桌面版。
2. 打开终端，进入合适的工作目录。
3. 克隆仓库：

   ```bash
   git clone https://github.com/yhx19960607-max/milktea.git
   cd milktea
   ```

4. 如果要运行爬虫或云端脚本，进入 `crawler/` 安装依赖：

   ```bash
   cd crawler
   npm install
   ```

5. 打开 Codex，选择「打开项目」/「打开文件夹」，选择当前 `milktea` 目录。
6. 让 Codex 先阅读本文件、`记忆.md` 和 `docs/` 下的资料，再继续开发。

## 日常开发流程

每次开始前：

```bash
git pull
```

完成修改后：

```bash
git add .
git commit -m "本次修改说明"
git push
```

## 文档更新规则

- 所有关键变更、结论、方案和下一步都需要写入本仓库。
- `README.md` 用于说明项目背景、开发流程和当前规则。
- `记忆.md` 用于记录项目阶段、业务共识和重要决策。
- `docs/` 用于存放较长的专项研究或方案。
- `docs/餐食识别模型方案.md` 记录餐食照自动识别暂缓和后续方案。
- 每次修改这些关键内容时，需要更新对应文档中的「更新时间」，格式为：`YYYY-MM-DD HH:MM`。
- 重要阶段变化时，也要在 `记忆.md` 中新增或更新对应条目，并写明日期。

## 版本管理规则

- 每次完成一个可识别的小阶段，就做一次 Git 提交。
- 提交信息要写清做了什么，例如「新增 README 开发说明」或「更新运动数据方案」。
- 开发前先拉取远端最新代码，避免不同电脑之间出现冲突。
- 不提交 `node_modules/`、临时文件、日志、密钥和本机私有配置。
- 如果生成新的依赖锁文件，例如 `crawler/package-lock.json`，建议提交，方便其他电脑安装一致版本。
